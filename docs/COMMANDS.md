# Commands and keyboard shortcuts

_Generated by `tools/gen_command_docs.py`._

Type a command or alias anywhere on the drawing (the letters go to the command line) and press Enter or Space. Enter or Space on an empty command line repeats the last command; Esc cancels. While a command asks for a point you can click (with grid snap, object snap and ortho) or type:

| Input | Meaning |
|---|---|
| `100,50` | absolute point in mm; origin at the sheet's lower-left corner, Y up |
| `@20,0` | relative to the last point |
| `@30<45` | polar: 30 mm at 45° (counter-clockwise from +X) |
| a number | distance, radius, angle or factor, depending on the prompt |
| a keyword | options shown in brackets, e.g. `[Undo/Close]` (the first letter is enough) |
| Enter / right-click | finish the command or accept the default `<…>` |

## Keyboard shortcuts

### Fixed keys

| Key | Action |
|---|---|
| Esc | Cancel the current command / tool, clear the selection |
| Enter / Space | Run the typed command, repeat the last command, finish a wire |
| Letters | Type a command or alias into the command line |
| R / M while placing | Rotate / mirror the symbol being placed |
| Space while drawing a wire | Flip the wire bend |
| Arrow keys | Nudge the selection by one grid step |
| + / - | Zoom in / out |
| Mouse wheel | Zoom at the cursor (Shift: pan sideways, Ctrl: pan up/down) |
| Middle button drag | Pan |
| Right click | Context menu; Enter while a command runs |
| Up / Down in the command line | Command history |
